# anxiety-recovery-tips
改善焦虑症的一些亲身经历和建议。【非专业人士，仅个人经验分享】

先说一下自己的情况：2024年的某个深夜，我陷入极度恐慌的状态，全身开始变得麻痹。我去了医院紧急检查，发现心脏毫无异状，医生怀疑是焦虑症，让我去精神科看一看。后来我确诊了焦虑症 (Anxiety Disorder)，并听医生的话开始服用药物。一年后，也就是2025年，我在医生的医嘱下，停止服用药物。这之后又来到了2026年，我的身心和思维上已经出现了很大的改变：我离开家乡，自己住在出租屋里，没有正式的工作，在出租屋Gap了一年。虽然现在的日子过得很拮据，但我已经能心安理得地接受事情的发生，能清楚地规划自己的计划。

直至今天，我不能说我已经100%痊愈，焦虑这个东西仿佛也没有“完全痊愈”这一说法，而更多是“持续性维护”。确诊焦虑症后的这段时间内，我确确实实地感受到了痛苦，同时也收获了很多。我这段时间所收获的，都会为我未来人生的生活打下很好的基础。

以下是我所遇到的问题和解决方法：

**1. 身体健康与生活作息**
**问题：**
- 皮肤很差，痘痘和痤疮很多，去过美容院、试过针清和昂贵的护肤品，依旧无效。
- 肠胃不好，经常胃疼、胃胀、胃酸倒流、胃灼烧、呕吐。
- 睡眠障碍。无法入睡，偶尔会在睡梦中惊醒。
- 对声音敏感。比较大且突然的声音（比如拍门声）会让自己的心脏狂跳且维持很长时间。
- 月经不调，可以长达几个月不来月经，出血量不稳定。
- 经常感到心慌、心悸、胸闷、呼吸困难。
- 症状加重时会进食困难，无法吞咽食物。
- 惊恐发作 (Panic Attack)。发作后的那份后怕感滞留的时间很长，需要一整天来消化。
- 不分昼夜地感到不舒服、不自在，无法正常地生活。

**方法：**
- 【非常重要！】 定期吃药和回诊，不可以擅自停药。
- 如果经期有问题，可以去看妇科医生。
- 不喝任何含有咖啡因的饮品。
- 获得充足的睡眠，即使你无法保证自己能做到早睡早起。
- 运动不是刚需，但基本的活动（比如散步、做家务）也有效果。
- 如果喜欢小动物，可以多去户外看一看动物：树上的鸟、别人遛的狗、散步的猫、湖里的鱼。如果能摸上，效果加倍。（不要被咬伤，最好提前了解动物的习性）


**2. 思想心态与认知调整
问题：**
- 脑中的画面或者声音无法停下，无法停止思考。
- 非常严重的拖延症，即使是重要的事情也会拖迟到最后一分钟。
- 一直怀疑自己，不相信自己的感受和判断。
- 之前想不起来的回忆，会在某些平凡的日子里陆陆续续地想起来，巨大的负面情绪会随之而来。
- 无法感知到自己的感受，也无法陈述自己的感受。

**方法：**
- 写下来，无论是脑中浮现的想法、感受到的心情、又或是毫无意义的画面，想到什么就写下来，无需去理会字迹好不好看、句子结构有没有逻辑，只管“输出”你的内容。（个人觉得用纸和笔的手写会更有效）
- 不去细想有关未来的事情，只关注当下。
- 学会认识自己的情绪，允许自己像个婴儿般去重新吸收一个你从未了解过的东西，有意识地去接收自己的感受和消化自己的情绪。
- 不去过度分析自己为什么会这样、别人为什么会这么对待自己、那件事情为什么会发生在我身上。可以去了解自己受到的伤害来源，但无需去追究到底，不要试图去找到一个“精准且正确”的逻辑，然后应用在你的每个遭遇来进行解释。


**3. 人际关系与社交调整
问题：**
- 长期为别人着想而忽略了自己的需求。
- 为了合群而耗尽精力去伪装自己的真实性格和想法，到最后一无所有。
- 过度依赖别人对自己的看法，从别人的嘴里认识自己。
  
**方法：**
- 远离让你觉得不舒服的地方，即使你对那些未知的地方感到恐惧。
- 对自己的人际圈来一个“大扫除”，迅速远离那些不适合你的人。
- 不要试图去改变或者拯救别人，即使在传统意义上，那个人是你非常重要的人。
- 找人倾诉。如果没有合适的人选，可以找 AI 倾诉（但不要过度分析自己）。
- 上网找一些跟你有相似经历的人，即使不用跟他们交流，你也能看到他们创作的内容（图文、视频），你或许能和这些素未谋面的网友达成共鸣。
- 远离社交媒体，不去关注其他人的生活，把关注放到自己身上。
- 多探索自我。无论是打零工或是下厨，努力去发现自己喜欢什么、不喜欢什么、向往什么、能做到什么、不能做到什么。目的就是为了认识自己。


**4. 爱好、行动与自我关怀**
**问题：**
- 对自己的生活没有半点掌控感，所有事情都像是被别人决定好了般。
- 思想上的巨人，行动上的矮人。想法太多，但心里各种纠结，不敢开始。

**方法：**
- 去户外，让身体接触一下阳光。
- 想做什么就做什么，无需等待自己变得完美才开始做，也无需以功利角度考虑做这件事情的后果（比如：你想用手机录一些有趣的东西并且发布在网上，你做这件事情是不需要去考虑这件事情对你的未来职业有没有实质性的帮助的，想做就去做）。
- 打从心底地对自己好。饿了就吃，累了就躺，听从自己的心声，遵循自己的真实需求。
- 可以暂时不考虑任何需要你付出巨大精力的事情，直到你能回到正常生活的状态。
- 建构一个完全属于自己的实体空间。比如：拥有自己的一个书桌，以你自己的想法去安排这个书桌的空间该怎么运用、该摆些什么上去，任何小事都全凭自己决定。
- 比起思考不动手，动手不思考会更好。找点事情来做，让自己忙起来。
